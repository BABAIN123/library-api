# Library API

Учебный проект библиотеки на FastAPI.

## Возможности

- Регистрация пользователей
- Авторизация через bcrypt
- CRUD для книг
- Работа с отзывами
- SQLite база данных
- Swagger
- HTML главная страница

## Стек

- Python
- FastAPI
- SQLite
- bcrypt
- requests
